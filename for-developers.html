เพิ่มความสามารถ 3 ด้านให้กับ Claude Code สำหรับแพลตฟอร์มกฎหมาย

⚖️

Legal AI Team

3 agents ฝั่ง Legal Advisory — Legal Advisor, Compliance Officer, Contract Specialist ทำงานร่วมกันตรวจสอบ compliance, ร่างสัญญา, และให้ Legal Opinion อย่างเป็นทางการ

📣

Marketing AI Team

4 agents ฝั่ง Marketing — Director, Content Creator, SEO Specialist, Social Media Manager ร่วมกันสร้าง content กฎหมายที่ถูกต้องและ optimize สำหรับ search

🤖

Automation Hooks

3 hook types ทำงานอัตโนมัติ — แจ้งเตือนเมื่อแก้ไขไฟล์กฎหมาย, บันทึก research insights, และแสดง checklist ท้าย session

Hook Types ที่มี

PreToolUse
ก่อนใช้ tool

แจ้งเตือนเมื่อแก้ไขไฟล์ที่ชื่อมีคำว่า legal, contract, terms, privacy, compliance — เพื่อให้ Legal Team ตรวจสอบก่อน

PostToolUse
หลังใช้ tool

แจ้งเตือนเมื่อสร้างหรือแก้ไข marketing assets และ legal documents — พร้อม PDPA compliance reminder

Stop
ท้าย session

แสดง team checklist — Marketing ส่ง content ให้ Legal review, Legal ยืนยัน compliance ก่อน publish

⚖️ Legal Commands

/legal/compliance-check
ตรวจสอบ PDPA compliance, ใบอนุญาตทนาย, และข้อกำหนดทางกฎหมายที่เกี่ยวข้อง
/legal/contract-analysis
วิเคราะห์และให้ความเห็นบนสัญญา — ความเสี่ยง, ช่องโหว่, และข้อแนะนำ
/legal/legal-review
Review content ที่มีประเด็นกฎหมายก่อน publish — ตรวจสอบโดย Legal Advisor
/legal/privacy-policy-review
ตรวจสอบ Privacy Policy ให้สอดคล้อง PDPA และมาตรฐาน international

📣 Marketing Commands

ติดตั้งใน 3 ขั้นตอน

ต้องการ: Claude Code CLI ติดตั้งแล้ว

1

Clone repo

ดาวน์โหลด plugin มายังเครื่อง

git clone https://github.com/seed18up/lawyer-near-me-claude-plugin.git
2

Copy .claude/ folder

วาง .claude/ folder เข้าไปใน root ของ project ที่ต้องการใช้งาน

cp -r lawyer-near-me-claude-plugin/.claude/ /path/to/your-project/

💡 หรือ copy folder .claude/ ด้วย File Explorer ไปวางที่ root ของ project

3

เปิด Claude Code และลองใช้

เปิด Claude Code ใน project directory แล้วรัน command แรก

/legal-news

🎉 Claude Code จะรัน pipeline 5 ขั้น — ดึงข่าว → สรุป → SEO → Legal Opinion → render HTML

หมายเหตุ: เนื้อหาทั้งหมดที่สร้างโดย plugin นี้เป็นไปเพื่อการศึกษาทั่วไป ไม่ใช่คำปรึกษาทางกฎหมาย ทุก content ที่จะ publish จริงต้องผ่าน Legal Advisor review ก่อน
