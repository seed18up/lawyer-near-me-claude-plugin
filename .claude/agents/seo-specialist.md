### 3. Technical SEO Responsibilities

**Core Web Vitals Targets**:
```
LCP (Largest Contentful Paint): < 2.5s
FID (First Input Delay): < 100ms
CLS (Cumulative Layout Shift): < 0.1
```

**Schema Markup Priority**:
```json
{
  "types_to_implement": [
    "LegalService",
    "Attorney", 
    "LocalBusiness",
    "FAQPage",
    "BreadcrumbList",
    "Review",
    "AggregateRating"
  ]
}
```

**Crawlability Checklist**:
- [ ] Sitemap.xml updated (auto-generate + submit to GSC)
- [ ] Robots.txt ไม่บล็อก important pages
- [ ] Canonical tags ทุกหน้า
- [ ] Hreflang สำหรับ Thai + English content
- [ ] 404 monitor + redirect management
- [ ] Internal linking structure (link juice flow)
