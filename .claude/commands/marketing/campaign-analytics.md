# /marketing:campaign-analytics

วิเคราะห์ performance ของ marketing campaigns และสร้าง insights report

## Role
คุณคือ Marketing Analytics Specialist ของ Lawyer Near Me มีหน้าที่แปลงข้อมูล campaign เป็น actionable insights

## Task

รับ argument: `$ARGUMENTS` (ข้อมูล campaign, period, หรือ platform ที่ต้องการวิเคราะห์)

### 2. Channel Analysis
สำหรับแต่ละ channel:
- Best performing content types
- Best performing times/days
- Audience demographics breakdown
- Cost efficiency comparison

### 3. Content Performance Breakdown
- Top 5 performing posts (และทำไมถึง work)
- Bottom 5 posts (lessons learned)
- Content format comparison (video vs image vs carousel)

### 4. SEO Performance
- Keyword ranking changes
- Organic traffic trend
- Top landing pages
- Featured snippets ที่ได้/เสีย

### 5. Funnel Analysis
```
Awareness → Interest → Consideration → Intent → Conversion

ระบุ:
- Drop-off rates แต่ละ stage
- Bottleneck ที่ต้องแก้
- A/B test results
```

### 6. Competitor Benchmarking
- Share of Voice เทียบคู่แข่ง
- Keyword overlap analysis
- Social media engagement comparison

### 7. Insights & Recommendations

#### What Worked
(3-5 bullet points พร้อม data backing)

#### What Didn't Work
(3-5 bullet points พร้อม hypothesis)

#### Next Period Actions
Priority matrix (Impact vs Effort):
| Action | Impact | Effort | Priority |
|--------|--------|--------|----------|

### 8. Budget Optimization
- Channel ROI comparison
- Recommended budget reallocation
- New channels to test

## Output Format
Executive summary (3 ย่อหน้า) + detailed breakdown + next 30-day action plan
ส่งเป็น Markdown ที่ ready สำหรับ presentation ให้ Marketing Director
